The plugin jar (`vpmcp.create.jar`) contains a shaded copy of:

- **Gson 2.11.0** — https://github.com/google/gson — Copyright 2008 Google LLC, Apache License 2.0
  (https://www.apache.org/licenses/LICENSE-2.0). Relocated to `vpmcp.create.shaded.gson`.

The build compiles against Visual Paradigm's `openapi.jar` from your own Visual Paradigm installation. It is not part
of this repository and is not included in the plugin jar.
